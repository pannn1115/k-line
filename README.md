# K 線翻譯機

把 K 線圖上的每一根 K 棒、每一條線，翻譯成沒有基礎的人也看得懂的說明。

## 功能
- **K 棒構造圖**：開盤、收盤、最高、最低、實體與上下影線
- **K 棒實驗室**：拖動拉桿自己做一根 K 棒，形狀和說明即時變化
- **互動 K 線圖**：點任一根 K 棒，逐項解說當天的 K 棒型態、成交量、均線、RSI、KD
- **逐日播放**：一天一天揭曉走勢，可暫停、調速度、拖時間軸
- **調整指標天數**：均線、RSI、KD 的天數都能調，直接看到線條怎麼變
- **換一支教學股**：重新產生一支虛構股票
- **型態小教室**：12 種常見型態，點卡片直接跳到圖上的實際例子
- **一句話重點**：點 K 棒先看結論，細節再展開
- **術語小字典**：虛線底線的詞，滑過或點一下就有解釋
- **新手引導**：第一次造訪自動帶你走一遍
- **手機浮動卡**：手機上點 K 棒，重點直接浮在畫面底部
- **色弱模式**：上漲 K 棒改成空心，不必只靠紅綠分辨

資料為程式產生的虛構「教學股」，僅供教學，不構成投資建議。

## 技術
- 單一 `index.html`，不需要建置或後端
- 圖表：[TradingView Lightweight Charts](https://github.com/tradingview/lightweight-charts) v5.2.1，放在 `lib/`，不依賴外部 CDN
